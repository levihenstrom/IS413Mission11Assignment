# Mission 11 - Bookstore App

## Setup

1. Install backend packages:

```bash
cd Bookstore.API
dotnet restore
```

2. Start the backend API:

```bash
cd Bookstore.API
dotnet run
```

3. Install frontend packages:

```bash
cd bookstore-client
npm install
```

4. Start the frontend:

```bash
cd bookstore-client
npm run dev
```

Frontend runs on `http://localhost:3000` and calls the API at `http://localhost:5043`.
